  <action>
    Create `src/services/geminiClient.ts`:
    - Interfaces: `GeminiModelInfo`, `GenerateContentParams`, `GeminiGenerateResponse`.
    - Methods:
      - `listModels(apiKey: string): Promise<GeminiModelInfo[]>`:
        Fetches `https://generativelanguage.googleapis.com/v1beta/models?key=${apiKey}`.
        Returns array with name, displayName, description, inputTokenLimit, outputTokenLimit, supportedGenerationMethods.
        Provides curated fallback models (`gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-1.5-flash`, `gemini-1.5-pro`) when offline or keyless.
      - `generateContent(apiKey: string, model: string, systemPrompt: string, userPrompt: string): Promise<string>`:
        Direct POST to `https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent?key=${apiKey}` with JSON payload.
      - `estimateTokens(text: string): number`: character-based heuristic token calculator (~4 chars per token).
  </action>
