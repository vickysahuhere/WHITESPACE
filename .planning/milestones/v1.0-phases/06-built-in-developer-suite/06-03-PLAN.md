    Create `src/components/browser/tools/RestTester.tsx`:
    - Method selector: `GET`, `POST`, `PUT`, `DELETE`, `PATCH`.
    - URL bar with developer presets (`https://api.github.com/zen`, `https://api.github.com/users/octocat`, `https://httpbin.org/get`, `https://httpbin.org/post`).
    - Tabs for request configuration:
      - `PARAMS`: Query parameters key/value table.
      - `HEADERS`: HTTP headers key/value table (e.g. `Content-Type: application/json`, `Accept: application/json`).
      - `BODY`: JSON raw text editor with "FORMAT JSON" button.
    - "SEND" button:
      - Executes live `fetch` with execution timer (`performance.now()`).
      - Captures response status, status text, execution time in ms, response headers, and body.
      - Handles CORS and network errors with clean failure diagnostics.
    - Response viewer:
      - Status pill: `200 OK`, latency (`142 ms`), payload size.
      - Response sub-tabs: `BODY` (formatted pretty-printed JSON with "COPY" button), `HEADERS` (key-value table), `COOKIES/METRICS`.
    - "SAVE TO SPACE DOCS" button:
      - Snapshots endpoint, method, headers, request payload, response status, and response JSON into a Markdown API documentation page in `DocumentContext` and triggers RAG re-indexing.
    - State persistence in `tab.data` and `BrowserContext.updateTab`.
