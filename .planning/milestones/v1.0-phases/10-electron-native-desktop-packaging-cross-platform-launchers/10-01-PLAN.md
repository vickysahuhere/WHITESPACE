  <name>Task 1: Assemble Electron main process and preload bridge with header stripper and permission grants</name>
  <files>electron/main.cjs, electron/preload.cjs</files>
  <read_first>src/types/index.ts, src/components/layout/TopBar.tsx</read_first>
  <action>
    Create `electron/main.cjs`:
    - BrowserWindow config:
      - `frame: false` (frameless aesthetic).
      - `backgroundColor: '#000000'`.
      - `minWidth: 1024`, `minHeight: 700`, default 1440x900.
      - `webPreferences`: `preload: path.join(__dirname, 'preload.cjs')`, `contextIsolation: true`, `nodeIntegration: false`, `webviewTag: true`.
    - Session header stripper (`session.defaultSession.webRequest.onHeadersReceived`):
      - Removes `x-frame-options`, `frame-options`, `content-security-policy`, and `content-security-policy-report-only` for iframe requests to allow developer embedding in OSS Browser tabs.
    - Media permission handler (`session.defaultSession.setPermissionRequestHandler`):
      - Automatically grants `'media'`, `'display-capture'`, `'notifications'`, and `'clipboard-read'` without annoying system popups.
    - IPC handlers:
      - `window-minimize`: minimizes window.
      - `window-maximize`: toggles maximize/unmaximize.
      - `window-close`: closes window.
      - `is-maximized`: returns window.isMaximized().
      - `get-platform`: returns process.platform ('win32', 'linux', 'darwin').
    - URL loader: loads `http://localhost:5173` in development or `dist/index.html` via `file://` in production.

    Create `electron/preload.cjs`:
    - Expose `window.whiteCollarsDesktop`:
      - `minimize: () => ipcRenderer.send('window-minimize')`
      - `maximize: () => ipcRenderer.send('window-maximize')`
      - `close: () => ipcRenderer.send('window-close')`
      - `isMaximized: () => ipcRenderer.invoke('is-maximized')`
      - `isDesktop: true`
      - `platform: process.platform`
  </action>
