    - Add `RAGChunk`: id, spaceId, sourceId, sourceType, sourceTitle, text, tokens, tokenCount, createdAt
    - Add `RAGSearchResult`: query, durationMs, totalChunksIndexed, matches: { chunk: RAGChunk; score: number; matchedTerms: string[] }[]
    
    Create `src/services/ragEngine.ts`:
    - Fast tokenizer: Lowercase, alphanumeric extraction, stopword filtering.
    - Sliding window chunker: 150-250 words per chunk with 30-word overlap, respecting sentence/paragraph boundaries.
    - Inverted Index structure:
      - `chunksMap`: Map<string, RAGChunk>
      - `invertedIndex`: Map<string, Map<string, number>> (term -> Map<chunkId, termFrequency>)
      - `docLengths`: Map<string, number>
      - `avgDocLength`: number
    - BM25 Scoring algorithm:
      - k1 = 1.2, b = 0.75
      - IDF calculated per query term
      - Term saturation and length normalization
    - Incremental methods:
      - `indexChunk(chunk: RAGChunk)`
      - `indexDocument(doc: Document)`
      - `indexSoul(space: Space)`
      - `indexTask(task: Task)`
      - `indexTab(tab: BrowserTab)`
      - `removeSource(sourceId: string)`
      - `clearIndex()`
    - Search method:
      - `search(queryText: string, options?: { spaceId?: string; scope?: 'active' | 'all'; topK?: number; minScore?: number }): RAGSearchResult`
      - High-resolution timing via `performance.now()`.
  </action>
